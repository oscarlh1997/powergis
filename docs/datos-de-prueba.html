Los 28 casos que cubren cada endpoint del motor, con el cuerpo exacto que espera y lo que debe responder. Viven en scripts/fixtures.json, así que no son documentación que se queda vieja: son el fichero que se ejecuta.

POST /v1/reports/{uuid}/upgrade → 202

subir a avanzado

firma sobre el cuerpoasíncrono · espera a la vavanzado

{
  "payment_reference": "pi_3PruebaStripe000",
  "force_refresh": false
}

Reutiliza la demografía ya calculada. `force_refresh: true` la recalcula, y sólo hace falta si los datos del almacén han cambiado. Devuelve 202: la ampliación se calcula en segundo plano, así que todo lo que necesite la v2 —PlaceRank el primero— tiene que esperar a que exista.

POST /v1/reports/{uuid}/placerank/rebalance → 200

firma sobre el cuerpo

{
  "economico": 0.4,
  "demografico": 0.3,
  "ambiental": 0.2,
  "match": 0.1

No toca la base de datos: recalcula sobre el snapshot. Devuelve el ranking COMPLETO, que es producto de pago, y por eso va firmado.

POST /v1/reports/{uuid}/downgrade → 200

bajar a básico

firma sobre el cuerpo

Cuerpo vacío {} — pero se firma igual.

Para reembolsos y contracargos. No borra la v2: deja de servirla. Va el ÚLTIMO de la tanda a propósito: deja el proyecto en básico, así que todo lo que necesita el avanzado —PlaceRank, GeoLens, exportaciones— tiene que probarse antes.

Operación interna

Clave interna, y en producción Traefik ni siquiera las publica.

X-Internal-Key

{
  "collector": "ine",
  "indicators": [
    "dem.pop.total",
    "dem.age.mean"
  ],
  "level": "provincia",
  "parent_code": "13",
  "period": null
}

Va a la cola `etl`, aislada de los informes. Estas rutas NUNCA salen a internet.

sincronizar el catálogo

X-Internal-Key

Cuerpo vacío {} — pero se firma igual.

El catálogo del código es la fuente de verdad; esto lo vuelca a la base.

GET /internal/coverage → 200

indicadores sin colector

X-Internal-Key

Un indicador huérfano nunca tendrá dato: saldrá como hueco y parecerá secreto estadístico.

GET /internal/ine/discover/2879 → 200

Necesita red hacia servicios.ine.es. `powergis endpoints` lo salta si no hay salida; con `--con-red` lo exige.
